# CZ-10B 1.0.1

最新九项反馈已修复，运行文件直接更新 KIU；提交记录以 Git 历史为准，KIU-Model 旧归档保持不动。离线渲染、实际检查、失败过程与修复边界见 local_workspace/CZ-10B/working/refinement_1.0.1/Report.html。

发射架恢复原始模型和 clamp 几何，仅调整 MODEL 轴向 roll 为180度、rocket 节点为 (0,-2.519,0)，默认加高段为0。箭体 MODEL 仍为45度；回收钩 MODEL 为0度并采用规范的表面安装方向。引擎舱仅一个通用 bottom 节点。旧载具请重新将发射架挂接到 bottom，重新挂接回收钩，或使用更新后的 Examples；不自动重写旧存档。

国旗保持3:2，长罩国旗/CHN上移6.4米。栅格舵为深灰钛合金色。三级间长度均保留完整外壁，挂钩采用平面定位标记。一级接口与原始下抱臂对齐。

载荷支架 B9 提供 Current（默认）和 Legacy。Legacy 复用迁移前内部锥体、加强筋与安装环，已移除旧外部筒段、外保温边圈及外圈碰撞体，避免与新二级冲突；使用12片内部锥体碰撞体。两样式的整流罩安装面相同，载荷顶部节点分别为1.569999695和1.266米；切换会移动顶部附着件。质量和价格保持不变。

YF-219EV／YF-219E 的 TQ-12 Waterfall scale 分别为1.9,1.9,3.5和0.9,0.9,1.6。两种模式均已实际点火并核对模板缩放。海平面喷管TVC环在内部不可见；真空模型和性能不变。

实机范围：原始夹具节点与释放、钛合金舵面、挂钩展开、两发动机喷流、最终内部旧支架的加载/往返切换/保存重载与长短罩组合。测试使用自有后台API，结束恢复环境；未做硬件鼠标拖放、完整上升/CBC/回收任务。历史推杆13%一级燃料/满载二级的1.049m/s分离记录仍属于之前的测试，本轮未改其参数。

## 保留的 1.0.0 构型与验证说明

以下保留迁移基线的安装方法、依赖和既有验证记录；当前1.0.1的方位与材质修正以上文及MODEL_VERSION.json为准。

- 级间段提供 7.65、6、4 米三档。YF-219EV 选用 6 米或 7.65 米；4 米用于较短的发动机构型。
- 一个可见固定半罩 Part 通过 B9 切换 12.10 米短罩／18.50 米长罩；旧长罩 Part ID 保留为隐藏的存档入口。
- 一级引擎舱提供七发／九发与六档下移高度。七发按现有全尺寸 YF-100 校准；九发已接入当前 YF-219E 海平面衍生稿。
- 二级支架提供单／双／三／四发。单发按 YF-219 校准，多发使用通用安装点。
- 两级燃料箱使用现有 ConfigurableTank。CBC 连接跨度、节点及上部接触垫板已匹配新外形。
- 发射架沿用原三种下部平台、两种上部净空和现有机构；当前节点高度适配下默认加高段为0；仍可按整箭长度调整。
- PF 基座使用新载荷适配器外观，沿用现有 PF 生成、分离、遮蔽与碰撞机制。

`Examples` 内的短罩／长罩 `.craft` 保存了七台 YF-100 的独立安装角度。可复制到 KSP 的 `Ships/VAB` 使用。新模型的轴向分界不同，旧载具应据新示例重新装配；本次不会改写已有用户载具或存档。

验证范围：源／MU 几何与动画、模型／贴图／切换／本地化引用已核对。KSP 中检查了构型切换、节点、ConfigurableTank 重复段与高亮、长短罩分离、PF 屏蔽解除、发射架机构、受控 CBC 分离及 RCS。此范围不等于完整上升、RSS/RO 运力或海上回收性能认证。

固定半罩沿用原有分离行为。0.8.1 固定适配器实际上没有独立气动遮蔽模块，本轮没有新增遮蔽插件；PF 版保留它自带的遮蔽。

YF-219 的原版燃料推力同步已修复。原版 TweakScale 与 Rescaled 均验证了双模式、1.25 倍缩放、实际点火、质量／价格和保存重载；组合 DLL 的栅格舵回归通过。RF 代码与相关配置保持既有实测版本的行为，点火次数保存证据保留。

依赖包括 KIU 既有的 `KIU.dll`、`ConfigurableTank.dll`、`KIUNetRecovery.dll`、`TowerControl.dll`，以及本目录 `Plugins/CZ10BFlightSystems.dll`。其它适配按相应 mod 的安装条件启用。测试控制 DLL 和诊断 Part 不随本模型发布。

## 2026-10-27 最终收尾

1.0.0的16项约定技术工作已完成。海平面YF-219E以真空母型为基础，上端推力架缩短0.50米，Nine安装面上移约0.583米；零下移时喷口外露约0.244米，为喉部至出口长度的25%。真空分支及性能参数不变，保留±8°单轴TVC。

两模式已实机核对RF配置、质量、VABO实际归类、点火、保存重载及剩余点火次数。Waterfall由同一B9模式选择器显式切换模板尺寸，并补齐四个随机激波控制器；最终日志无YF219缺失控制器警告。两种模式共用一个Part目录项。

最终九发模型六档载入及节点检查通过。正常Pitch／Yaw／Roll记录包含原生双轴合成约11.31°的滚转姿态；据此将隔热短边从175毫米缩至50毫米，六档36组实测姿态网格复核无穿插。正式发动机MU和DLL未改。

九发中心发动机相对外围径向安装基准额外转−45°，中心节点为nineEngine0；外围使用标准径向对称朝向。旧九发载具需要重新挂接发动机。七发继续使用engine0及现有YF-100安装方案。

最终定向复验使用1倍尺寸的RF地面受控夹具，不代表完整上升或真空高度性能资格；此前两版TweakScale等基线证据与这次模型／喷流复验分开记录。

完整可编辑源归档位于KIU-Model的 `CZ-10B/versions/v1.0.0-final`，游戏版本仍为1.0.0。三份源从实际归档位置独立重开通过，贴图已打包，无缺失图像和外链库；此前v1.0.0里程碑保持不变。归档提交及运行资产哈希见MODEL_VERSION.json。
